Which client movement functions the server's copy (`modules/server/crates/poe-game/src/clientsim.rs`, `clientpath.rs`) ports, generated by `scripts/re/movement_coverage.py` (do not edit by hand; rerun it after a doc or port changes, with the same `--session` arguments as below). Plan: [sync-tools.md](../plans/sync-tools.md).

One row per client function (0.5.5h) named in [movement-click](movement-click.md), [movement-positioned](movement-positioned.md), [movement-roll](movement-roll.md), [movement-sprint](movement-sprint.md), [movement-capture-index](movement-capture-index.md), [pathfinding](pathfinding.md), the "Clicking an object" section of [world-travel](world-travel.md#clicking-an-object), or logged by the DLL feature `unported_log` ([client-dll.md](../architecture/client-dll.md)). An address inside a function counts for that function. 34 addresses outside `.text` (globals, vtables) are not listed.

Status:
- `cited`: a server source file names an address in the function (usually its port).
- `partial`: cited, and `unported_log` flags a part the server lacks (its site name in brackets).
- `no`: flagged by `unported_log`, not cited.
- empty: not cited. Many of these are not movement rules (input, rendering, network, containers) and need no port.

Session columns: player frames with an `UNPORTED` line for the function (`scripts/re/unported.py`). `snap-known` is `runtime/game-test/snap-known-20261119-174004` (warp onto a checkpoint, walk out), `walk` is `runtime/game-test/walk-20261119-174920` (open ground, a wall stop, a roll: no hits).

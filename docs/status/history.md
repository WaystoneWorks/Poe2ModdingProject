# History

What was built when, newest last. Detail lives in the topic docs linked from each line. Open work is in [../PLAN.md](../PLAN.md); terrain progress in [terrain.md](terrain.md).

- **2026-10-12, foundation and login.** Repo, tools, config, data access (Bundles2, `.datc64`), the `version.dll` proxy and deploy tooling. Login works end to end: key exchange (DLL crypto bypass), authentication by machine hash, character creation and selection, Standard and Hardcore leagues ([../protocol/login.md](../protocol/login.md), [../re/crypto.md](../re/crypto.md)).
- **2026-10-13, first zone.** Hand-off, encryption, area info, inventories, player entity and initial state; start position on the Riverbank shore, character deletion, exit to character selection, heartbeats, pause, chat joins, non-Steam shortcut ([../protocol/instance.md](../protocol/instance.md), [../protocol/entities.md](../protocol/entities.md), [../architecture/instance-world.md](../architecture/instance-world.md), [../guides/setup.md](../guides/setup.md)).
- **2026-10-14, movement and debug suite.** WASD, click-to-move, dodge roll, pause, saved area and position ([../protocol/movement.md](../protocol/movement.md)). The DLL became a permanent loader plus a hot-reloadable core with a Vulkan imgui overlay, packet capture and read-only operation on official servers ([../architecture/client-dll.md](../architecture/client-dll.md)); first official captures compared with ours ([../re/captures.md](../re/captures.md)).
- **2026-10-15, facing and terrain tooling.** The player faces the cursor. Area export with hash self-check, generator trace, seed sweep; the generator reproduced Clearfell and the Riverbank ([../re/terrain/README.md](../re/terrain/README.md)).
- **By 2026-10-16, dungeon layouts.** `.dgr` areas ported (G1_3, G1_6 to G1_9; [../re/terrain/dungeon.md](../re/terrain/dungeon.md)).
- **2026-10-17, instances and chat.** Instance directory, transfers, forced layouts, chat channels, server commands in chat and the overlay ([../guides/server-admin.md](../guides/server-admin.md), [../guides/hosting.md](../../modules/server/docs/hosting.md)).
- **2026-10-20, restructure.** Docs, scripts and runtime data moved into the current layout; protocol and client hook became submodules; datamined outputs moved to `dumps/`.
- **2026-10-20, server-authoritative movement.** Movement spec from official captures, `poe-game` (`World`, `GridSource`, the old `Locomotion` model and replay tests, deleted 2026-11-03), the server owns the player's position; the DLL's position reports only feed the opt-in drift checker (`[dev] drift_check`). Verified in game: WASD, rolls, click-to-move, held click ([../protocol/movement.md](../protocol/movement.md#roll-path-and-speed-profile)).
- **2026-10-20, accounts and standalone login.** `poe-accounts` (argon2id over the client's digest, roles, per-cluster rolling tokens), `0x0003` credentials, the DLL's `login_mode = "standalone"` patch and `trusted_servers`, patcher skip via `--success-event 0`; password and remember-me logins verified in game ([../re/standalone-login.md](../re/standalone-login.md), [../architecture/accounts.md](../architecture/accounts.md), [../guides/setup.md](../guides/setup.md#config-key-changes)).
- **2026-10-20, remote readiness, web API, launcher.** Terrain layout and grid upload over the instance TCP port, the HMAC-authenticated per-session side channel (`PSS` v1), `[network.login] public_port` ([../protocol/side-channel.md](../protocol/side-channel.md)). `poe-web-api` and the Poe2WebAdmin SPA ([../architecture/web-api.md](../architecture/web-api.md)). Poe2Launcher (Tauri 2 + Svelte 5) with `POST /api/v1/game-token` auto-login ([../guides/launcher.md](../guides/launcher.md)).
- **2026-10-20, remote players.** Other players decoded from an official town capture ([../protocol/entities.md](../protocol/entities.md)); one task per instance owns one `World` shared by its sessions, with remote `AddObject` on join, same-frame relay and the official leave sequence ([../architecture/instance-world.md](../architecture/instance-world.md#the-instance-actor)).
